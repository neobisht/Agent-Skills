# Agent-Skills
A collection of useful agent skills I've built, collected, and experimented with to make AI agents better at everyday tasks.


## Skills

- **socratic-tutor** — Turns an LLM into a personal tutor that teaches a topic of your choice using the Socratic method: a diagnostic, a skill map with levels 0–5, one question at a time, spaced review, and a final assessment.

## How to use

With a coding agent that supports the common `SKILL.md` format, copy the skill directory into your agent's skills folder, then ask the agent to use it ("teach me X").

With a plain chatbot, paste the contents of the skill's `SKILL.md` into the chat (or into a custom/system prompt), followed by what you want it to do.
